# Setup Instructions for ChatGPT Project

To deploy MenuGen as a custom ChatGPT Project, follow these steps.

## Create the Project

1. Open ChatGPT in your browser.
2. In the left sidebar, under **Projects** click **+ New Project**.
3. **Project Name:** `MenuGen`

---

## Apply the Project Instructions

1. Click on the `MenuGen` will bring Project settings window.
2. Copy the entire content of your `instructions.md` file and paste it into the **Instructions** field. 
3. Save the instructions.

## 3. Test the Project

1. Start a new chat inside the **MenuGen** project.
2. Test that it works by uploading into the chat window the example/original_menu.jpg.
