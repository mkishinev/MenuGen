# Setup Instructions for Gemini Gem

To deploy MenuGen as a Gemini Gem, follow these steps.

## Create the Gem

1. Open the Gemini web application in the browser.
2. Locate the left-hand sidebar and click on **Gems**.
3. Click the **+ New Gem** button in the **My Gems** section.

---
## Configuration
1. **Name:** Enter `MenuGem`.
2. **Description:** Enter `Generate menu with pictures.`
3. Copy the entire `instructions_gemini_gem.md` file content and paste it into the **Instructions** text box.
4. Click **Update** in the top right corner.

---

## Test the Gem
1. Start a new chat inside the **MenuGen** Gem.
2. Test that it works by uploading into the chat window the example/original_menu.jpg.
