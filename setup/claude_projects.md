# Setup Instructions for Claude Project

To deploy MenuGen as a custom Claude Project, follow these steps.

## 1. Create the Project

1. Open the Claude web or desktop application.
2. In the left-hand sidebar, click **Projects**.
3. Click **+ New Project** and give it a name: `MenuGen`.

## 2. Apply the Project Instructions

1. Inside the project, locate the **Instructions** field and click **+** (this is the system prompt applied to every conversation in the project).
2. Copy the entire contents of `instructions.md` and paste them into the **Instructions** box.
3. Save / confirm the changes.

## 3. Test the Project

1. Start a new chat inside the **MenuGen** project.
2. Test that it works by uploading into the chat window the example/original_menu.jpg.
